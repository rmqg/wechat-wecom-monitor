# 兼容性与边界

版本：0.1.0。许可证：MIT。

| 路径 | 前提 | 不保证的内容 |
|---|---|---|
| 离线 demo / 统一导出检查 | Python 3；合成或合法 chat-export/v1 目录 | 不代表真实客户端可读 |
| 微信本地库 | 已同步的本地库、对应密钥、适配的库结构及可选依赖 | 不保证任意 Linux/macOS/Windows 客户端版本 |
| 企微本地库 | Windows 采集器支持的环境、本地库与已有密钥 | 不保证所有版本、账号和媒体类型 |
| chat-send/v1 | 提供方命令可用、明确目标、客户端状态正确 | 不保证 UI 永不变化或 unknown 可自动恢复 |
| Bark | 自行配置服务和凭据 | 不保证公网服务可用性、隐私或送达 |

没有自动密钥获取，不包含真实密钥、账号、生产配置或数据库。不支持通过升级承诺兼容；升级客户端前自己备份私有配置和状态，先在隔离副本评估，不修改原库。

chat-export/v1 / chat-send/v1 是五仓库集成边界，见 CONTRACT。其他生产方只要遵守格式即可接入；格式一致不等于该平台本地采集已获测试。源客户端未同步的消息、缺失群、未知类型和缺失媒体必须如实暴露，不能宣称全覆盖。

演示只验证合成流程，文档不宣称任何特定真实客户端版本已经验证。
